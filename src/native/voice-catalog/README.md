# Native voice catalog foundation

This host helper enumerates actual eSpeakNG provider records without speech synthesis or audio-device initialization. The portable client reuses POSIX spawn/pipe/poll and validates a fully owned snapshot. Source integration into the guest AVFAudio framework still requires runtime-owner verification before Firefox's missing class or public behavior can be reported as resolved.

The provider runs once per helper process. Modern status-returning initialization distinguishes missing data from a successful empty catalog. No InitializeOutput, callback, synthesis or voice-selection function is used. Default eSpeakNG data discovery applies; no helper option introduces a data path or library override. A provider failure emits an error envelope and a matching nonzero exit. A complete catalog is copied before provider termination and no host pointer is serialized. Abnormal process death or output failure may produce no complete envelope; a consumer must reject it. The helper has bounded output and memory, but its local provider calls have no internal wall-clock deadline.

The public eSpeakNG 1.52.0 GPLv3-or-later headers and source specify its API and lifecycle: [speak_lib.h](https://github.com/espeak-ng/espeak-ng/blob/1.52.0/src/include/espeak-ng/speak_lib.h), [espeak_ng.h](https://github.com/espeak-ng/espeak-ng/blob/1.52.0/src/include/espeak-ng/espeak_ng.h), [modern initialization](https://github.com/espeak-ng/espeak-ng/blob/1.52.0/src/libespeak-ng/speech.c), [legacy initialization](https://github.com/espeak-ng/espeak-ng/blob/1.52.0/src/libespeak-ng/espeak_api.c), [enumeration](https://github.com/espeak-ng/espeak-ng/blob/1.52.0/src/libespeak-ng/voices.c). Legacy espeak_Initialize can return a sample rate after failed initialization with DONT_EXIT, so it cannot provide the required error distinction. ListVoices(NULL) excludes MBROLA and variant voices in the cited provider source.

## Build and verify

Build this directory with the host compiler in a separate build directory. Dependencies are ICU's `uc` component and the published eSpeakNG development headers. The provider library is optional at runtime and is loaded nonfatally through its normal host SONAME. Do not supply guessed header declarations.

```sh
cmake -S /path/to/src/native/voice-catalog -B /outside/checkout/voice-build \
  -DESPEAK_NG_INCLUDE_DIR=/path/to/public/header/root \
  -DCMAKE_C_FLAGS='-Wall -Wextra -Werror'
cmake --build /outside/checkout/voice-build -j1
ctest --test-dir /outside/checkout/voice-build --output-on-failure
```

Controlled providers are compiled only into dedicated test helpers through a compile-time path. Production has no environment variable or CLI mechanism for switching libraries. The independent provider client uses the real documented API in a separate process, without the production encoder or normalization code, and compares every actual raw identity/name/gender/language priority. A missing or truly empty actual provider returns skip 77, never a positive populated-provider result. Other controls cover initialization/list/termination errors, duplicate identities, UTF8 rejection, exact capacity, ownership after provider mutation, allocation failures and deterministic identity ordering. Client tests reject every truncation boundary, malformed lengths/version/status/UTF8/identity/primary metadata and trailing bytes; fail each decoder allocation; and exercise real child execution, timeout after stdout closes, excess output, nonzero exit, missing executable, closed standard descriptors and child reap.

`tests/public-before.m` is a frozen original dynamic AVFoundation caller for the runtime owner. It exits 20 with MISSING_CLASS on the current runtime. An argument-free success establishes only class signatures. Its nonempty-catalog path additionally requires an independently produced expected JSON projection with voices containing identifier/name/language, and currentLanguageCode. Official Apple documentation supplies those typed selectors; quality/gender numeric values are deliberately not guessed. No native helper result qualifies that public path, Firefox UI, speech, GPU or stability.

## Version 1 wire format

All integers are unsigned 32-bit little-endian, with no padding, pointers or terminating NUL bytes. A string is its byte length followed by UTF8 bytes. Envelope: magic `QVVC`, version 1, status, exact total bytes, record count, provider string `espeak-ng`. Status values are the project `qv_catalog_status` enum, never Apple or provider error numbers. Errors carry zero records.

Each record: provider gender, language count, primary-language index, provider identifier string, project identifier string, display-name string, then language entries. Each entry: provider priority, raw language string, canonical language string. Empty canonical string means explicitly unsupported; primary UINT32_MAX means no supported canonical language. The decoder validates complete lengths/counts/UTF8/identities, reconstructs the exact project identifier/canonical projection/primary selection and rejects trailing bytes or partial results. The returned snapshot owns all strings and records independently of the wire bytes.

Limits: 4 MiB total, 4096 records, 64 languages per record, 1024 bytes per provider string. Project identifier is the fixed prefix `org.qvolution.voice.v1/espeak-ng/` followed by uppercase percent encoding of every provider-identifier byte except RFC3986 unreserved ASCII; its derived bound is prefix length plus three times the provider identifier bound. Record order is provider-identifier UTF8 byte order; identity never uses display name/index. Duplicate provider identities are rejected. Publication is transactional, including when the destination is one byte short.

## Language policy and remaining integration

[ICU's public locale API](https://unicode-org.github.io/icu-docs/apidoc/released/icu4c/uloc_8h.html) validates complete input and canonicalizes case/locale aliases. This initial adapter accepts a bounded subset: known ISO language, optional known script, optional ISO country. The script must resolve through ICU's public uscript_getCode to its matching four-letter short name; unknown and private-use scripts are unsupported. Unsupported dialects, extensions, macroregions or newer language subtags are retained verbatim with an empty canonical value. Legacy eSpeak en-sc/en-wi/en-uk are explicitly unsupported because treating dialect labels as ISO regions would change their meaning. This is a deliberate coverage limit, not a claim that all unsupported labels are invalid BCP47. Primary language is the lowest provider priority, then lexical canonical tag; no hardcoded English fallback exists.

The client uses an absolute executable path, bounded stdout pipe and a monotonic collection deadline after spawn returns. Failure cleanup signals only its checked positive spawned PID and reaps it; kernel spawn/reap calls have no claimed hard deadline. Darwin's existing execve implementation supports ELF directly, avoiding new server RPC or guest-to-host function ABI. Darwin and host native behavior still require separate runtime evidence. Different ICU versions that produce different canonical projections fail validation explicitly.

The partial AVFAudio source class exposes only documented factories/current-language/identifier/name/language selectors. It copies real projected records, omits records with no mapped canonical primary explicitly, and leaves unresolved quality/gender/coding/traits/audio-settings selectors absent. Identifier lookup never fabricates a voice; language selection tries exact canonical match then same-language priority/identifier order, with nil using the user's NSLocale current languageIdentifier independently of the provider. Enumeration is fresh per call, so a failure cannot become a permanent successful empty cache. Provider failure and successful empty remain distinct internally and in diagnostics. The original full-contract fixture deliberately continues to require scalar signatures; a separate frozen partial-field fixture verifies this narrower slice. No speech synthesis, browser workflow, UI, GPU or stability is qualified by source compilation.
