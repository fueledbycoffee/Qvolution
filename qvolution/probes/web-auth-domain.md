# Web authentication session error-domain data export

The vendored Foundation NSError header defines the domain as an NSString pointer (rung2).

The spelling `com.apple.AuthenticationServices.WebAuthenticationSession` is independently present in the official Meta API-client [LoginManager.swift CanceledLoginErrorDomains](https://github.com/facebook/facebook-ios-sdk/blob/9a682148e9d5be7930c8c90bb982b6b57bf228e1/FBSDKLoginKit/FBSDKLoginKit/LoginManager.swift#L56), pinned upstream file commit9a682148e9d5be7930c8c90bb982b6b57bf228e1. Only the public interface fact/literal is used; no SDK implementation code is copied.
